# PickyLens v0.1 visual identity

Approved small-control direction: compact, unobtrusive, understandable and compatible with the host without implying native host branding.

- Small embedded controls: simplified glasses mark. Composer label: PickyLens · Review. Answer label: Check answer. Use the same compact visual language, subtle whole-control hover and visible keyboard focus. No surrounding card in the idle state; results may expand after activation.
- Larger branding, landing pages, README and future mascot surfaces: a cute intelligent brain wearing those glasses. This rule does not require new artwork for the current milestone.
- Personality: smart, slightly picky, friendly, never intrusive.
- Avoid shields/security imagery, magnifying glasses/search imagery and generic robots.

The embedded icon/text gap is 5px. Control size, placement and behavior remain unchanged. No full brain mascot in small embedded controls.
